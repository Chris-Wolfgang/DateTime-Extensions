EndOfWeek(DateTime, DayOfWeek)

Returns a new DateTime that represents the last tick of the week specified by the DateTime passed in using the specified firstDayOfWeek. Clamps at MaxValue when the week would extend past the end of the representable range.

public static DateTime EndOfWeek(this DateTime dateTime, DayOfWeek firstDayOfWeek)

Parameters

dateTime DateTime

The value to process.

firstDayOfWeek DayOfWeek

Specifies the first day of the week. Use the parameterless overload to pick up CurrentCulture's value automatically.

Returns

DateTime

A new DateTime representing the end of the week.

Examples

var moment = new DateTime(2026, 9, 24, 14, 30, 45, 678);
var end = moment.EndOfWeek(DayOfWeek.Monday);
// 2026-09-27 23:59:59.9999999 - the last tick of the Sunday that ends that week

Remarks

Counts forward from dateTime to the day before the next firstDayOfWeek and returns that day's last tick. It does not go through FirstOfWeek(DateTime, DayOfWeek), so it does not inherit that method's MinValue clamp: within the first six days of year 1 the result is still the correct day, and the method is idempotent over the whole representable range (#436, #468).

Exceptions

ArgumentOutOfRangeException

firstDayOfWeek is not a defined DayOfWeek value.

FirstOfWeek(DateTime)

Returns a new DateTime that represents the first day of the week specified by the DateTime passed in using the thread's CurrentCulture FirstDayOfWeek.

public static DateTime FirstOfWeek(this DateTime dateTime)

Parameters

dateTime DateTime

The value to process.

Returns

DateTime

A new DateTime representing the first of the week.

Examples

var moment = new DateTime(2026, 9, 24, 14, 30, 45, 678);
var first = moment.FirstOfWeek();
// The current culture decides which day starts the week, so this value is
// machine-dependent. Under an invariant culture the week starts on Sunday
// and the result is 2026-09-20. Use the overload below to be explicit.

FirstOfWeek(DateTime, DayOfWeek)

Returns a new DateTime that represents the first day of the week specified by the DateTime passed in using the specified firstDayOfWeek

public static DateTime FirstOfWeek(this DateTime dateTime, DayOfWeek firstDayOfWeek)

Parameters

dateTime DateTime

The value to process.

firstDayOfWeek DayOfWeek

Specifies the first day of the week. Use the parameterless overload to pick up CurrentCulture's value automatically.

Returns

DateTime

A new DateTime representing the first of the week.

Examples

var moment = new DateTime(2026, 9, 24, 14, 30, 45, 678);
var first = moment.FirstOfWeek(DayOfWeek.Monday);
// 2026-09-21 00:00:00.0000000 - the Monday before Thursday 24 September

Remarks

Within the first six days of year 1 - 0001-01-01 through 0001-01-06 - walking back to firstDayOfWeek can underflow the representable range. Rather than throw, this method clamps to MinValue, which is itself a Monday and so is not guaranteed to fall on firstDayOfWeek. The clamp is confined to this method: EndOfWeek(DateTime, DayOfWeek) counts forward from the instant and is unaffected.

Exceptions

ArgumentOutOfRangeException

firstDayOfWeek is not a defined DayOfWeek value.
